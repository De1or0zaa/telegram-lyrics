# 🎵 Telegram Lyrics Bot

Бот для Telegram, который пошагово «печатает» текст песни, редактируя одно и то же сообщение. Слово за словом текст появляется на экране — как будто кто-то набирает его в реальном времени.

## Возможности

- **Поиск текстов** — по названию песни или формату `Исполнитель - Название` через lrclib.net и lyrics.ovh API
- **Ручной ввод** — вставка текста напрямую (`/type` или `/paste`) для любых языков, включая русский
- **Прогрессивная анимация** — бот редактирует одно сообщение, добавляя по N слов каждые S секунд
- **Выбор из результатов** — если найдено несколько вариантов, бот предложит выбрать через inline-кнопки
- **Настраиваемые параметры** — количество слов за редактирование и задержка между ними
- **Целевой канал** — можно настроить бота писать анимацию в указанный Telegram-канал
- **Остановка** — команда `/stop` для прерывания текущей анимации
- **Деплой на Railway** — готовый Procfile и конфигурация

## Команды

| Команда | Описание |
|---------|----------|
| `/start` | Приветствие |
| `/help` | Подробная справка |
| `/play <запрос>` | Найти песню и запустить анимацию |
| `/type <текст>` | Анимировать переданный текст |
| `/paste` | Режим вставки (следующее сообщение = текст) |
| `/words <N>` | Кол-во слов за редактирование (1–50) |
| `/delay <S>` | Задержка между редактированиями (0.8–30 сек) |
| `/target <@канал>` | Установить целевой канал для анимации |
| `/settings` | Текущие настройки |
| `/stop` | Остановить анимацию |

## Быстрый старт

### 1. Создайте бота в Telegram

Напишите [@BotFather](https://t.me/BotFather) и создайте нового бота:
```
/newbot
```
Получите токен вида `123456789:ABCdefGHIjklMNOpqrSTUvwxYZ`.

### 2. Локальный запуск

```bash
# Клонируйте репозиторий
git clone <your-repo-url>
cd telegram-lyrics-bot

# Создайте виртуальное окружение
python -m venv venv
source venv/bin/activate  # Linux/Mac
# venv\Scripts\activate   # Windows

# Установите зависимости
pip install -r requirements.txt

# Установите токен
export BOT_TOKEN=ваш_токен_здесь

# Запустите бота
python bot.py
```

### 3. Деплой на Railway

#### Вариант A: Через Railway Dashboard

1. Зарегистрируйтесь на [railway.app](https://railway.app)
2. Создайте новый проект → **Deploy from GitHub repo**
3. Подключите репозиторий с ботом
4. В разделе **Variables** добавьте:
   - `BOT_TOKEN` = ваш токен от BotFather
   - (опционально) `WORDS_PER_EDIT` = 3
   - (опционально) `DELAY` = 1.5
5. Railway автоматически определит `Procfile` и запустит бота

#### Вариант B: Через Railway CLI

```bash
# Установите Railway CLI
npm install -g @railway/cli

# Авторизуйтесь
railway login

# Инициализируйте проект
railway init

# Установите переменные окружения
railway variables set BOT_TOKEN=ваш_токен_здесь

# Задеплойте
railway up
```

### 4. Добавьте бота в канал

1. Добавьте бота в свой Telegram-канал как **администратора**
2. В чате с ботом отправьте: `/target @username_вашего_канала`
3. Теперь все анимации будут публиковаться в канале

### Ключевые компоненты

- **Поиск текстов**: `search_lrclib()` + `search_lyrics_ovh()` — два API с fallback
- **Анимация**: `animate_text()` — разбивает текст на чанки по N слов и пошагово редактирует сообщение
- **Настройки**: `ChatSettings` dataclass + JSON-файл для персистентности
- **FSM**: режимы `waiting_for_lyrics` и `selecting_song` для многошаговых взаимодействий

## Ограничения

- Telegram позволяет редактировать сообщение ~1 раз в секунду; минимальная задержка установлена в 0.8 сек
- Длина одного сообщения — до 4096 символов; для очень длинных текстов бот обрежет с пометкой
- Поиск текстов работает лучше для англоязычных песен; для русских используйте `/type` или `/paste`
- На Railway файловая система ephemeral — настройки сбрасываются при перезапуске контейнера
